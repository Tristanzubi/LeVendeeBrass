# 🍽️ LeVendéeBrass

Projet de site web mettant en valeur une brasserie fictive en bord de mer, avec une ambiance marine et des spécialités régionales des Pays de la Loire.

---

## 🌊 À propos 

Nous étions 4 à travailler sur ce projet, ce qui nous a permis de collaborer efficacement et de répartir les tâches. Avec une petite aide de nos formateurs si besoin, nous avons pu avancer et résoudre les défis rencontrés.  

Nous avons créé une API simple pour gérer la carte du restaurant ainsi que le personnel, afin de structurer et centraliser ces données.  

Le site propose également une fonctionnalité de réservation en ligne simulée côté client, sans base de données.

---

## 🌟 Objectifs du projet

- Créer une **interface responsive** mobile-first avec React  
- Simuler une **expérience utilisateur complète** pour un restaurant  
- Intégrer une **fonction de réservation** (sans backend)  
- Suivre une **organisation agile** avec la méthode SCRUM  

---

## 🛠️ Stack technique

- **Front-end** : React (Vite)  
- **Routing** : React Router  
- **Styles** : CSS (mobile-first)  
- **Formulaire** : gestion des états avec React  
- **API** : Express.js (API simple pour le menu et le personnel)  
- **Outils de travail** : Git, Figma, Trello  

---

## 📂 Gestion de projet & Git Workflow professionnel

Pour assurer un développement collaboratif et structuré, nous avons utilisé un **Git Workflow professionnel** avec :  
- Création de branches dédiées pour chaque fonctionnalité ou correction de bug  
- Utilisation de **Pull Requests** pour intégrer les modifications après revue par l’équipe  
- Revue de code systématique avant fusion dans la branche principale (`dev`)  
- Gestion des conflits et suivi rigoureux des versions via Git  
- Collaboration via plateformes comme GitHub ou GitLab  

Cette organisation a permis de garantir la qualité du code et une bonne communication entre les membres de l’équipe.

---

## 📅 Méthode Agile : SCRUM

Ce projet a été organisé en suivant la méthode **SCRUM**, afin de favoriser la collaboration, la flexibilité et la qualité du produit final.  
Principaux éléments mis en œuvre :  
- Découpage du travail en **sprints** courts  
- Utilisation d’un **backlog** pour prioriser les tâches  
- Réunions régulières (daily stand-up) pour suivre l’avancement  
- Revue de sprint et rétrospective pour améliorer le processus  

Cette démarche a permis de garder une bonne visibilité sur le projet et de s’adapter rapidement aux besoins.

---
